# BALL DASH ROYALE

3Dボール転がしのオンライン対戦レースゲーム。最大6人まで同じ部屋に入って、ジャイロ操作で迷路をかけぬけ、ゴールの穴に最初に落ちた人が勝ちです。

## 🎮 特徴

- **3D迷路レース**: Three.js + Cannon-es 物理エンジンによるリアルな転がりと衝突
- **回転できる三人称視点**: ドラッグでカメラを回せて、移動方向も視点に追従
- **ジャイロ操作（直感マッピング）**: スマホの **奥を下げる → 画面の上へ進む**。ボタンで前後反転も可能
- **オンライン対戦**: PeerJS による合言葉ベースのP2Pマッチ。最大6人
- **CPU対戦**: BFS経路探索＋体当たりAI。スキル調整あり
- **カスタマイズ**: 名前と16色からボールカラーを選択
- **スター争奪ルール**: 3つ集めるとゴールが開くコレクト＆ゴール方式
- **戦闘**: DASH体当たりとSHOOT弾で相手を吹き飛ばし、スターを落とせる
- **明るいデザイン**: ネオン系を排した、空・草原テイストの陽気なビジュアル

## 🆕 今回のアップデート（v1.2）

### コアルール
- **コレクト＆ゴール方式**: スターを3つ集めるまでゴール穴が開かないため、自然に争奪戦が発生
- **ミニマップとゴール矢印を廃止**: 直接誘導をなくし、ステージ把握と駆け引きを重視
- HUDはスター所持数とゴール開放状態を表示

### 視点・操作
- ドラッグ視点操作を追加し、カメラの向きに合わせて移動方向が変わるように改善
- タッチ／マウスのドラッグ対象を調整し、ボタンやジョイスティックと干渉しにくく改善
- **ジャイロ操作を再調整**: 奥を下げると画面上へ進む向きを正しくし、画面回転補正・角度ラップ補正・小入力のスナップ停止・斜め入力正規化を追加
- HUDに**ジャイロ感度 − / ＋**を追加し、0.55〜1.85倍で調整可能

### 戦闘
- **SHOOT** ボタン（PCはEキー）を追加
- 弾が当たるとダメージ＋ノックバック、さらに相手のスターを1つ落とす
- オンラインではクライアントのDASH/SHOOT入力もホストに送られるよう改善

### 新オブジェクト
- **地雷**: 近づくと爆発し、周囲のボールをまとめて吹き飛ばす。弾を当てて遠隔起爆も可能
- **バンパー**: ピンボールのように触れたプレイヤーを弾く固定障害物。Cannon-esの物理ボディも追加してすり抜けを防止
- **動く壁の当たり判定強化**: 見た目の移動に合わせて物理ボディも同期

## 🆕 以前のアップデート（v1.1）

### 操作性
- ジャイロの **前後マッピングを再修正** — 奥を下げると画面の上へ進む（直感どおり）
- HUDに **FLIP** ボタンを追加（前後反転をワンタップで切替）
- **応答カーブ** 導入: 小さい傾きはやさしく、大きい傾きで素早く反応
- デッドゾーン拡大（手の震えで勝手に動かない）
- ステアリング感度UP（moveForce 9 → 13.5、maxSpeed 10.5 → 12.5）
- 逆方向に倒したら少しブレーキがかかる仕様で切り返しが軽快に
- 物理サブステップ増（高速時の貫通防止）

### マップ
- **正方形 17×17 → 長方形 25×19 に拡大**
- 中央に大きな 4×4 アリーナ＋3つの 3×3 アリーナ（PvP乱戦エリア）
- ループ通路を増量（同じ場所に複数ルート）

### 新ハザード
- ❄ **氷ゾーン** — 摩擦ゼロでツルツル滑る
- ⬛ **動く壁（ムーバー）** — 通路を行ったり来たり
- ⚡ **レーザーゲート** — ON/OFF を繰り返し、当たると吹き飛ぶ
- 🌀 **テレポート** — ペアになっていて瞬間移動！

### 戦闘
- **ボディスラム**: ダッシュ中に他人にぶつかると 1.9倍 のノックバック
- ダッシュ攻撃の判定窓を 360ms に拡張、上方向の浮きも追加
- ぶつかった時の閃光がスラム時は黄色になる演出

## 🕹 操作

### スマホ
- 左右に傾ける → 左右に転がる
- **奥(上端)を下げる** → 画面の **上** へ進む
- HUD: **DASH**（体当たり）／**SHOOT**（弾攻撃）／**RESET**（基準姿勢を再設定）／**FLIP**（前後反転）／**−・＋**（ジャイロ感度）

### PC
- WASD / 矢印キー: 移動
- スペース: ダッシュ体当たり
- E: ショット攻撃
- R: ジャイロ基準を再設定
