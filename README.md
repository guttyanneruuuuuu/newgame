# BALL DASH ROYALE

3Dボール転がしのオンライン対戦レースゲーム。最大6人まで同じ部屋に入って、ジャイロ操作で迷路をかけぬけ、ゴールの穴に最初に落ちた人が勝ちです。

## 🎮 特徴

- **3D迷路レース**: Three.js + Cannon-es 物理エンジンによるリアルな転がりと衝突
- **三人称視点**: ボールのすぐ後ろからの低めの視点で「迷路の中にいる」感
- **ジャイロ操作（直感マッピング）**: スマホの **奥を下げる → 画面の上へ進む**。ボタンで前後反転も可能
- **オンライン対戦**: PeerJS による合言葉ベースのP2Pマッチ。最大6人
- **CPU対戦**: BFS経路探索＋体当たりAI。スキル調整あり
- **カスタマイズ**: 名前と16色からボールカラーを選択
- **アイテム**: 黄色のリングを取るとブースト（速度上限UP）
- **明るいデザイン**: ネオン系を排した、空・草原テイストの陽気なビジュアル

## 🆕 今回のアップデート（v1.1）

### 操作性
- ジャイロの **前後マッピングを再修正** — 奥を下げると画面の上へ進む（直感どおり）
- HUDに **FLIP** ボタンを追加（前後反転をワンタップで切替）
- **応答カーブ** 導入: 小さい傾きはやさしく、大きい傾きで素早く反応
- デッドゾーン拡大（手の震えで勝手に動かない）
- ステアリング感度UP（moveForce 9 → 13.5、maxSpeed 10.5 → 12.5）
- 逆方向に倒したら少しブレーキがかかる仕様で切り返しが軽快に
- 物理サブステップ増（高速時の貫通防止）

### マップ
- **正方形 17×17 → 長方形 25×19 に拡大**
- 中央に大きな 4×4 アリーナ＋3つの 3×3 アリーナ（PvP乱戦エリア）
- ループ通路を増量（同じ場所に複数ルート）

### 新ハザード
- ❄ **氷ゾーン** — 摩擦ゼロでツルツル滑る
- ⬛ **動く壁（ムーバー）** — 通路を行ったり来たり
- ⚡ **レーザーゲート** — ON/OFF を繰り返し、当たると吹き飛ぶ
- 🌀 **テレポート** — ペアになっていて瞬間移動！

### 戦闘
- **ボディスラム**: ダッシュ中に他人にぶつかると 1.9倍 のノックバック
- ダッシュ攻撃の判定窓を 360ms に拡張、上方向の浮きも追加
- ぶつかった時の閃光がスラム時は黄色になる演出

## 🕹 操作

### スマホ
- 左右に傾ける → 左右に転がる
- **奥(上端)を下げる** → 画面の **上** へ進む
- HUD: **DASH**（体当たり）／**RESET**（基準姿勢を再設定）／**FLIP**（前後反転）

### PC
- WASD / 矢印キー: 移動
- スペース: ダッシュ体当たり
- R: ジャイロ基準を再設定
