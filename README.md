# Aether Drift: Ascension

**オンライン対戦対応・ジャイロ操作対応の宇宙シューティングゲーム**

## 🎮 ゲーム概要

Aether Drift: Ascensionは、プレイヤーが宇宙の奥深くで敵と戦うアクションシューティングゲームです。ジャイロセンサーを活用したモバイル操作とPeerJSを使用したリアルタイムオンライン対戦機能を備えています。

## ✨ 主な機能

### オンライン対戦（VS モード）
- **PeerJS統合**: 合言葉ベースのフレンド対戦システム
- **リアルタイム同期**: 位置、HP、スコア、チャージ状態をリアルタイム同期
- **相手の射撃表示**: ピアバレット表示で対戦状況を可視化
- **90秒タイムアウト判定**: HP比較による自動判定
- **VS戦績記録**: 勝敗数の永続保存

### ゲームプレイ
- **ステージシステム**: 複数のステージとボス戦
- **ハザード**: 障害物や危険な環境要素
- **パワーアップシステム**: 武器強化やシールド取得
- **パーティクル効果**: 爆発やエフェクト表現
- **ジャイロ操作対応**: DeviceOrientationEventによる傾き操作

### UI/UX
- **グラスモーフィズムデザイン**: 洗練された半透明UIパネル
- **通貨表示**: ゲーム内通貨（コイン）の管理
- **ステータス画面**: プレイヤー情報の表示
- **ゲーム内メニュー**: 直感的なナビゲーション

## 🎨 デザイン特性

- **カラースキーム**: 深い青紫グラデーション背景
- **アクセントカラー**: 蛍光色（シアン、マゼンタ）
- **テーマ**: ダークテーマ
- **レスポンシブ**: モバイルファースト設計

## 🚀 デプロイメント

このプロジェクトはVercelにデプロイされています。

**デプロイメントURL**: https://newgame.vercel.app

## 📋 技術スタック

- **フロントエンド**: HTML5, Canvas API, JavaScript
- **通信**: PeerJS (WebRTC)
- **デバイスAPI**: DeviceOrientationEvent (ジャイロ)
- **ブラウザストレージ**: localStorage (VS戦績保存)

## 🎯 オンライン対戦の使い方

1. ホーム画面から「VS対戦」を選択
2. ホストまたはゲストを選択
3. 合言葉を入力または共有
4. 接続完了後、ゲーム開始
5. 90秒間の対戦
6. 結果判定（HP比較）

## 📱 対応デバイス

- PC（ブラウザ）
- スマートフォン（ブラウザ）
- タブレット（ブラウザ）

# ローカルサーバーで実行
